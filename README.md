# Smart Electricity Consumption Dashboard

## 1. Project Overview
The Smart Electricity Consumption Dashboard is an interactive Power BI project developed to analyze electricity consumption and building performance. It helps monitor energy usage, track electricity bills, and identify consumption patterns across different building types.

## 2. Project Objectives
- Analyze overall electricity consumption.
- Monitor monthly electricity bills.
- Compare energy usage across building types.
- Identify high energy-consuming buildings.
- Generate meaningful insights for better energy management.

## 3. Tools & Technologies Used
- **Power BI Desktop** – Dashboard creation and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculations and KPI measures.
- **Microsoft Excel** – Dataset management.

## 4. Dashboard KPIs
- Total Units
- Total Buildings
- Total Bill
- Average Consumption

## 5. Visualizations Used
- Waterfall Chart – Units by Building Type.
- Stacked Column Chart – Monthly Energy Consumption.
- Treemap – Building-wise Energy Usage.
- Line Chart – Monthly Electricity Bill Trend.
- Table – Building-wise Monthly Energy Consumption.
- Donut Chart – Energy Consumption Distribution.

## 6. Interactive Filters
- Month
- Building Type
- Building Name

## 7. Key Insights
- Identifies the highest electricity consumption month.
- Highlights the month with the highest electricity bill.
- Identifies the lowest consumption month.

## 8. Project Outcome
This dashboard provides a clear view of electricity consumption patterns and supports better monitoring, comparison, and energy management decisions.
